# Maps — Curated Visual Maps

> **Mermaid diagrams here are visual aids only.** Their edges are captions, not data: they do
> **not** appear in Obsidian's Graph View. The real graph is the set of typed, justified
> relationships inside the concept notes (internal wiki links). If a map and a note ever disagree,
> **the note wins** — update the map.

| Map | Scope |
|---|---|
| [`course-flow.canvas`](course-flow.canvas) | **Hand-laid learning-flow board** (Obsidian Canvas — fixed positions, no physics; the "organized" view of the graph) |
| [`map-csharp.md`](map-csharp.md) | C# language concepts (established + the C/C++ backlog hook) |
| [`map-unity.md`](map-unity.md) | Unity engine concepts (13 notes) + the design-workflow entry point |

| [`map-track-cross-disciplinary.md`](map-track-cross-disciplinary.md) | **Track C** bridge map: L36, design side ↔ implementation side (Phase 2a) |

Each map contains:

1. A **Mermaid diagram** — a curated, readable view of the territory.
2. A **real-links table** — the pairs that must exist as internal links inside the notes, with the
   reason each link is real (source: the lesson's `06-concept-links.md` tables).

Validation of the actual link data: [`Graph-Validation/validate-graph.ps1`](../Graph-Validation/validate-graph.ps1).
