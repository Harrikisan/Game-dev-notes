# 04-Questions/Combined-Assessments

> Assessments that deliberately span **both** tracks — the "whole course" view.
> Use these to test whether design concepts and technical implementation connect, not to
> re-test single-track material.

## Scope

- Cumulative papers covering Game Development + Game Design lessons (e.g., end-of-module,
  end-of-semester practice papers).
- Cross-track questions that are genuinely joint, e.g.:
  - *Given a design requirement (X mechanic), choose and justify an implementation approach
    taught in class.*
  - *Given an implemented system (e.g., enemy wave system), identify the design decisions
    it embeds (difficulty curve, pacing, player experience).*
  - *Evaluate a prototype against design-thinking stages taught in L60.*

## Rules

1. Every item must be answerable from course material; mark which lessons feed it.
2. Section the paper: Game Development part · Game Design part · Cross-track part — so
   partial revision still works.
3. Traceability + no-official-provenance rules from `04-Questions/README.md` apply.
4. When an item is single-track, place it in that track's folder instead; this folder is
   for items that genuinely require both.
