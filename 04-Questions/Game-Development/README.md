# 04-Questions/Game-Development

> Question banks for **GAME_DEVELOPMENT** lessons — the technical/engineering track
> (C# programming, Unity engine implementation, graphics programming with OpenGL/C++).

## Scope

- Lessons whose `metadata.yaml` says `primary_track: GAME_DEVELOPMENT` (canonical list:
  `00-Dashboard/GAME-DEVELOPMENT-INDEX.md`).
- Lessons from other tracks with a substantive GAME_DEVELOPMENT secondary track may also
  contribute; label which lesson and which technical aspect each question targets.

## Question emphasis (from the v2 question-bank template)

Heavier use of the code-oriented categories:

- **Code interpretation** — read instructor-reconstructed code and explain it.
- **Predict the output** — reasoning + execution flow, not just the answer.
- **Debugging scenarios** — symptom → ordered checkpoints → fix → prevention.
- **Practical implementation** — step lists with verification (e.g., set up a prefab,
  wire an AudioMixer snapshot, build a NavMesh agent).

## Rules

1. Traceability to the lesson's `08-source-reference.md` (timestamps live only there).
2. Never claim official-exam provenance.
3. Instructor-incorrect statements are never reproduced as fact — apply the corrections
   logged in the lesson's `08` corrections table.
4. Stay within patterns the lesson actually taught; extension material is labeled
   `SUPPLEMENTARY`.
